# F11 · F0.4 Mobile UI Kit — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The reusable native building blocks every Phase 1–3 screen needs — form fields, select, date/time and KZT money inputs, cover image picker, confirm sheet, empty/error states, a list screen, and PDF/CSV/ICS sharing — so work packages only compose screens.

**Architecture:** Pure logic (value parsing, validation, file names) lives in small `.ts` modules with vitest tests, reusing shared rules (`parsePrice`, `priceInput`, `zonedInput`, `toInstant`, `zoneLabel`, `calendarFileName`). Components live in `mobile/src/kit/*.tsx`, built only from the existing `ui.tsx` primitives and `theme.ts` tokens, re-exported from `mobile/src/kit/index.ts`. Components are verified by typecheck, native export, and a dev-only **UI kit gallery** screen for on-phone checks (React Native components cannot render in the vitest node environment).

**Tech Stack:** Expo SDK 58 (Expo Go modules only): `@react-native-community/datetimepicker`, `expo-image-picker`, `expo-file-system` (new `File`/`Paths` API), `expo-sharing`; React Native `Modal`, `FlatList`; vitest.

**Spec:** `docs/superpowers/plans/2026-11-26-mobile-native-rebuild.md` § F0.4.

## Global Constraints
- Branch `feat/f11-f0-4-ui-kit-slyamshaikhov` from `master` 78fbd50 or later. No Claude attribution anywhere.
- Only theme tokens from `mobile/src/theme.ts` (no new colours); touch targets ≥ 44 pt; every control has an accessibility label/role; kk/ru/en for every new string (`mobile/src/kit/copy.ts`).
- Money is entered and stored as tiyn integers via shared `parsePrice` / `priceInput` (no floats). Dates are entered as wall time in the **event's** IANA zone and converted with shared `toInstant` (rejects DST gaps/overlaps); the zone is always shown (`zoneLabel`).
- Cover image rules come from one shared place used by web and mobile: JPEG/PNG/WebP, ≤ 5 MB (today hard-coded in `web/src/events/CoverEditor.tsx`).
- Files: protected downloads go through `session.request(..., { responseType: "blob" })` (never a raw token in a URL); written to the cache directory; shared via the OS share sheet.
- No web behaviour change except `CoverEditor.tsx` importing the shared cover rules. `npm run check` green after every task; `npm run export:mobile` green at the end.

## Review Focus
- Device time zone ≠ event time zone (phone in Almaty UTC+5, event in `Europe/Moscow`) → picked 19:00 is saved as 19:00 Moscow, and shown back as 19:00 with the Moscow label.
- Hermes `Intl` with a non-device `timeZone` (shared `zonedInput` depends on it) → works on Android and iOS; if it does not, the field shows an error instead of saving a shifted time.
- Money text with spaces, comma decimals, more than 2 decimals, or > safe integer (`"1 500,5"`, `"10.999"`) → clear inline error, value never silently rounded.
- Image picker returns HEIC (iPhone default) or > 5 MB → rejected with the shared message before any upload; picker permission denied → explained, not a crash.
- Share sheet cancelled, or offline download → no unhandled rejection; temp file cleaned or overwritten next time.

**Files:**
- Create: `frontend/shared/src/features/events/cover.ts` (`coverRules = { types: ["image/jpeg","image/png","image/webp"], maxBytes: 5 * 1024 * 1024 } as const`; `coverProblem(file: { type?: string | null; size?: number | null }): "type" | "size" | null`), test `frontend/shared/tests/features/events/cover.test.ts`; add `"events/cover"` to `moved` and `stubExempt` in `shared/tests/features.test.ts`.

- Create: `frontend/mobile/src/kit/values.ts`, `frontend/mobile/src/kit/values.test.ts`.

**Interfaces — Produces (`values.ts`):**
- `moneyValue(text: string): { amount: number | null; error: "price" | null }` — trims, removes spaces and NBSP between digits, empty → `{ amount: null, error: null }`, else shared `parsePrice` (catch → `error: "price"`).
- `moneyText(amount: number | null): string` — `""` for null, else shared `priceInput`.
- `wallFromPicker(date: Date): string` — the device-local Y-M-D h:m of the picked `Date` as `YYYY-MM-DDTHH:mm` (the picker works in device time; we only take its wall clock).
- `instantFromWall(wall: string, zone: string): { iso: string | null; error: "date" | null }` — shared `toInstant`, errors mapped to `"date"`.
- `pickerDateFromInstant(iso: string | null, zone: string): Date` — shared `zonedInput(iso, zone)` wall parsed as a **device-local** Date, so the picker opens on the event's wall time; null → now rounded to the next hour.

### Task 2: File sharing

**Files:** Create `frontend/mobile/src/files.ts`, `frontend/mobile/src/file-names.ts`, `frontend/mobile/src/file-names.test.ts`; `npx expo install expo-file-system expo-sharing`.

**Interfaces — Produces:**
- `file-names.ts`: `safeFileName(base: string, extension: "pdf" | "csv" | "ics" | "png"): string` — same rule as web ticket PDFs (`/[^a-z\d_-]/gi` → `_`, max 100 chars, empty → `"biletflow"`), plus `.ext`; `mimeFor(extension)` → `application/pdf`, `text/csv`, `text/calendar`, `image/png`.
- `files.ts`: `downloadAndShare(path: string, base: string, extension): Promise<"shared" | "unavailable">` — `session.request<Blob>(path, { responseType: "blob" })` → base64 (reuse `blobToDataUri` from `tickets/model.ts`, strip the `data:…;base64,` prefix) → write to `new File(Paths.cache, safeFileName(...))` (overwrite) → `Sharing.isAvailableAsync()` false → `"unavailable"`, else `Sharing.shareAsync(uri, { mimeType, UTI })` → `"shared"`. Errors propagate as `ApiError` / `Error` for the caller's error state. Before writing, check the exact `File` write signature in `node_modules/expo-file-system/build/*.d.ts` (SDK 58).

- [ ] Step 1: tests for `safeFileName` (`"TKT-1/2 ü"` → `"TKT-1_2__.pdf"`, 200-char input → 100 + ext, `""` → `"biletflow.csv"`) and `mimeFor` → FAIL; Step 2: implement both files; Step 3: PASS, `npm run check` green.

### Task 3: Kit components

**Files:** Create in `frontend/mobile/src/kit/`: `copy.ts`, `FormField.tsx`, `Select.tsx`, `DateTimeField.tsx`, `MoneyInput.tsx`, `ImageField.tsx`, `ConfirmSheet.tsx`, `States.tsx` (`EmptyState`, `ErrorState`), `ListScreen.tsx`, `index.ts`. `npx expo install @react-native-community/datetimepicker expo-image-picker`.

**Interfaces — Produces (props):**
- `FormField({ label, hint?, error?, children, nativeID })` — label/hint/error stack; error text is `accessibilityLiveRegion="polite"` and in `danger` colour.
- `Select<T extends string>({ label, value: T | null, options: {value:T,label:string}[], onChange, placeholder?, error? })` — pressable field opening the existing `Sheet` with a radio list.
- `DateTimeField({ label, zone, value: string | null /* ISO */, onChange(iso: string | null), error?, locale })` — shows `formatDateTime` in `zone` + `zoneLabel`; Android: date then time dialogs; iOS: inline `mode="datetime"` in a `Sheet`; uses `wallFromPicker` / `instantFromWall` / `pickerDateFromInstant`; invalid wall → `error` copy, `onChange` not called.
- `MoneyInput({ label, amount: number | null, onChange(amount: number | null), error?, locale })` — numeric keyboard, `₸` suffix, keeps the raw text while typing, reports `moneyValue` on blur.
- `ImageField({ label, imageUri: string | null, onPick(file: { uri: string; name: string; type: string }), onRemove?, busy?, locale })` — `expo-image-picker` library picker (`mediaTypes: ["images"]`, `quality: 0.85`), runs `coverProblem` and shows the shared kk/ru/en messages `coverType` / `coverSize` from `@biletflow/shared/features/events/copy`; permission denied → message + "open settings".
- `ConfirmSheet({ visible, title, body, confirmLabel, tone: "danger" | "primary", busy?, onConfirm, onCancel })`.
- `EmptyState({ title, body?, action? })`, `ErrorState({ code?, onRetry, locale })` (copy: "Could not load…", shows `(code)`).
- `ListScreen<T>({ data: T[] | undefined, renderItem, keyExtractor, header?, empty, error?, onRetry, refreshing, onRefresh, onEndReached?, loadingMore? })` — `FlatList` + pull-to-refresh + footer spinner; `undefined` data → loading text.
